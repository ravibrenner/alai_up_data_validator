# ALAI UP Data Validator

Intended for use with the [ALAI UP Dashboard](https://github.com/alai-up/alai_up_local_dashboard).

The purpose of the Data Validator is to support clinics in preparing their data for use in the Dashboard. The data validator does the following:
- Checks for data that does not comply with the Data Dictionary
- Checks for logical inconsistencies (e.g. out of order events, outcomes that don’t match a client’s history)
- Checks for missing data in important data fields
- Generates a report that identifies potential inconsistencies and missingness in the data

You can access the data validator online at https://alai-up.github.io/alai_up_data_validator/
